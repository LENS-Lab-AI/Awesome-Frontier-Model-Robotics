# Contributing

**Quickest way:** [submit a title and link](https://github.com/LENS-Lab-AI/Awesome-Frontier-Model-Robotics/issues/new?template=submit-resource.yml). That's all we need to get started; we'll check the source and format the entry.

Papers, reports, benchmarks, tools, and documented demos are welcome. You can submit your own work.

## Prefer a Pull Request?

1. Check that the resource isn't already listed.
2. Add one short entry to the relevant section in `README.md`:

```markdown
- **[Title](source-url)** (Month Year) — Author/team. One short sentence on the work. [Code](code-url)
```

3. Open a PR. Link any related submission issue and thank its submitter.

Credit the original authors, link their source, and note whether the work uses simulation or real robots. Omit unavailable links; no detailed summary is needed. Maintainers can help with edits.

**Something wrong?** [Report a correction](https://github.com/LENS-Lab-AI/Awesome-Frontier-Model-Robotics/issues/new?template=correction.yml).

Original contributions use [CC0](LICENSE); linked works keep their own licenses.
